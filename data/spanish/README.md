# Spanish definitions

Chinese translations come from [jmjm93/cedict-translations](https://github.com/jmjm93/cedict-translations),
derived from CC-CEDICT. See `LICENSE-CEDICT` and `meta.json` for licence and pinned source.
These are machine translations, with a subset reviewed by the repository author.
The exact entry hash includes the simplified headword, pinyin and original English senses;
unmatched entries retain English rather than using another entry's translation.

Japanese definitions use applicable JMdict Spanish glosses, with English fallback when an entry
has no Spanish glosses for the selected spelling and reading.
Copyright EDRDG, CC BY-SA 4.0; see [JMdict attribution](../japanese/README.md).
The bilingual index is stored separately in `data/japanese/jmdict-es.sqlite3`.

Install or refresh both with `.venv\Scripts\python.exe tools/setup_spanish.py`, then restart.
No API key is needed to download or use these dictionaries.
